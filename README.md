# TER-Redshift

## Overview
This project explores redshift estimation using MacSum-based neural network architectures for interval prediction.

## Structure
- `src/` - Source code
- `configs/` - Training configurations
- `data/` - Datasets
- `notebooks/` - Jupyter notebooks
- `ressources/` - Resources

## Usage
Train with:
```bash
python -m src.training.training --config configs/config_training_1.toml --epochs 10
```
